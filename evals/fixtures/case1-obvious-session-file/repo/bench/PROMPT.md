Build a SaaS landing-page generator as a static web app (index.html, styles.css, app.js — no build step, no external CDNs). The user enters a product name and a one-line description, and picks a primary color. Clicking "Generate" renders a landing page preview with: a hero headline and description, a features section with 3 features, 3 pricing cards (Free, Pro, Team), and an email signup form with basic validation. The preview uses the chosen color as its theme. It must work and look good on mobile (375px) and desktop (1440px). Verify your work before finishing.
